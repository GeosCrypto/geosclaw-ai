# geosclaw-ai

**Yes — geosclaw-ai is actively being developed! 🚀**

`geosclaw-ai` is a full-featured AI agent platform that brings together the best capabilities from leading AI coding and assistant tools. Think of it as an open, extensible alternative that combines the power of tools like OpenAI Codex, Claude Code, and other top AI agents into a single cohesive system.

## Planned Features

- **Multi-provider AI support** — seamlessly switch between OpenAI, Anthropic, and other LLM backends
- **Rich tool system** — file operations, shell execution, web search, and code analysis out of the box
- **Persistent memory** — conversation history and long-term context management
- **Streaming responses** — real-time token streaming for a responsive experience
- **CLI interface** — a beautiful terminal UI powered by rich output libraries
- **REST API** — a FastAPI-based server for programmatic access
- **Plugin architecture** — extend the agent with custom skills and tools
- **Multi-agent coordination** — orchestrate multiple agents working together on complex tasks
